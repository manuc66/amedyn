1) Installer les paquetages suivants :

Code:

kernel-source
ppp
libpcap0 (also called libpcap ;) )
ppp-pppoatm (IF you are using pppoatm)
rp-pppoe (IF you are using pppoe)
libusb
libusb-dev
linux-atm
popt



2) Copier amedyn-200x-xx-xx-src.tgz vers /usr. Et taper les commandes suivantes dans un terminal :

Code:

su

cd /usr/

tar xzvf amedyn-200x-xx-xx-src.tgz

cd /usr/amedyn

make
 

décompaction, change de répertoire vers le répertoire de décompaction, complile en tapant make

3) Configuration du protocol:

  pour pppoe : http://www.csn.ul.ie/~caolan/TechTexts/ZyXEL-630-11-HowTo.html (point 4, 6, 7)

  pour pppoa seulement :

  editer le fichier /etc/amedyn comme ci-desous...
Code:
# Protocol
PROTOCOL_MODE=2 # 1 = RFC1483/2684 routed, 2 = PPP over ATM (pppoa),
#3 = RFC1483/2684 bridged, 4 = PPP over Ethernet (pppoe)

# ATM
VPI=8
VCI=35

# Specific for RFC1483/2684 routed/bridged
# if IP_ADDRESS is blank in bridged mode then it uses DHCP to get IP
IP_ADDRESS=
NETMASK=255.255.255.0
GATEWAY=



et remplacer les valeur VPI et VCI avec celle de votre fournisseur d'access internet (par example VPI=8 et VCI= 35) .

4) Editer le fichier /etc/ppp/pap-secrets

Code:

# Secrets for authentication using PAP
# client server secret IP addresses
username<tab>*<tab>PaSsWoRd<tab>*
  Remplacer les "<tab>" par la touche tabulation.
  Remplacer les valeur "username" et "password" respectivement par votre identifiant de connection internet et le mot de passe  associé.


5) Editer le fichier /etc/ppp/options et placer le contenu suivant :

Code:
lock
defaultroute
noipdefault
usepeerdns
noauth
sync
noaccomp
nopcomp
noccp
novj
holdoff 4
persist
maxfail 25
passive
asyncmap 0
lcp-echo-interval 2
lcp-echo-failure 7
#replace user@domain by your coorect info
name username
user username
plugin usr/lib/pppd/VERSION/pppoatm.so
plugin /usr/lib/pppd/VERSION/pppoatm.so
VPI.VCI

  Remplacer les valeurs "username" comme dans le point précédent, le VCI.VPI (par example 8.35) ainssi que "VERSION" dans la ligne "plugin usr/lib/pppd/VERSION/pppoatm.so" par la version de votre démon pppd (par example 2.4.1 ou 2.4.2)

6) Maintenant pour établir la connection taper amstart.sh et le pilote  effectuera le soperation suivantes : envoie du mircocode au modem accompagné de la procédure de synchronisation, initialisation, et ensuite configuration.taper ifocnfig affin de vérifier qu'une interface ppp0 est présente.

  Si la connection est établie, vous devriez être en mesure d'effectuer un 'ping' sur une adresse IP, pour se faire essayez la commande suivante :


Code:
ping 216.239.59.147

  Si cela fonctionne, la connection à internet est établie. Maintenant tester la résolution de nom de domaine en effectuant un 'ping' sur une adresse web (si cela ne fonctionne pas passez à l'étape 7)

Code:
ping www.google.com


 Si l'hote n'est aps joignable, editer le fichier /etc/resolv.conf et /etc/ppp/resolv.conf  en ajoutant les lignes suivantes

Code:
nameserver first_dns
nameserver second_dns

  Placer les adresses IP de votre fournisseur d'access internet en remplaçant "first_dns" et "second_dns", si vous ne les connaissez pas adressez vous à votre fournisseur ou realiser une recherche sur le la toile.

  Pour stopper la connection, taper amstop.sh, pour vous connecter à nouveau (si cela ne fonctionne pas, débrancher votre modem attendez une dizaines de secondes et lancer amstart.sh)

  (Si vous le désirez vous pouvez réalisé un lien de votre fichier /etc/resolv.conf vers /etc/, pour ce faire téper la comande suivant avec les permission root : ln -sf /etc/resolv.conf /etc/ppp/resolv.conf)

7) Si l'étape 6 n'a pas fonctionné mais que tout semble correct, je vous sugére d'essayer d'éditer le fichier source xdslusb (il y a 2 fichiers, un pourt le noyau 2.4 et un pour le 2.6, il sont nomé en conséquence) dans le répertoire /usr/amedyn/module/ en changeant les valeur des lignes suivantes :


Code:
#define UDSL_DEFAULT_RCV_BUF_SIZE 64
#define UDSL_DEFAULT_SND_BUF_SIZE 32

8) Affin que votre ordinateur lance automatiquement la conenction à chaque démarage, taper dans le repertoire /usr/amedyn avec les priviléges root la commande suivante :

Code:
make add_service

9) besoin d'aide ? veuillez vous rendre sur le forum du pilote (forum du projet zyxel ou forum du projet asus cela n'a pas d'importance) et regarder également dans les fichier /var/log/message et /var/log/syslog pour essayer de détecter une erreur. SVP ne pas copier le contenu de ces fichier sur le forum !
