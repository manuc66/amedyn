1) Instala los siguientes paquetes :

Quote:

kernel-source
ppp
libpcap0 (También identificado como libpcap ;) )
ppp-pppoatm (Si estas usando pppoatm)
rp-pppoe (Si estas usando pppoe)
libusb
libusb-dev
linux-atm
popt
popt-dev



2) Copia amedyn-200x-xx-xx-src.tgz to /usr. Escribe el siguiente comando en el shell :

Quote:

su

cd /usr/

tar xzvf amedyn-200x-xx-xx-src.tgz

cd /usr/amedyn

make
 

Cuando termine la descompresión , entra en el nuevo directorio, y compila escribiendo make

3) Configura tu protocolo:

para pppoe : http://www.csn.ul.ie/~caolan/TechTexts/ZyXEL-630-11-HowTo.html [en ingles] (puntos 4, 6, 7)

para pppoa sólo :

Edita el fichero /etc/amedyn como se muestra a continuación...
Quote:
# Protocol
PROTOCOL_MODE=2 # 1 = RFC1483/2684 routed, 2 = PPP over ATM (pppoa),
#3 = RFC1483/2684 bridged, 4 = PPP over Ethernet (pppoe)

# ATM
VPI=8
VCI=35

# Specific for RFC1483/2684 routed/bridged
# if IP_ADDRESS is blank in bridged mode then it uses DHCP to get IP
IP_ADDRESS=
NETMASK=255.255.255.0
GATEWAY=



y reemplaza los valores de VPI y VCI con los que indique tu ISP

4) edita /etc/ppp/pap-secrets

Quote:

# Secrets for authentication using PAP
# client server secret IP addresses
username<tab>*<tab>PaSsWoRd<tab>*
Reemplaza <tab> con la tecla de tabulación.
Reemplaza con tu nombre de usuario/clave.

5) edita /etc/ppp/options y esribe:

Quote:
lock
defaultroute
noipdefault
usepeerdns
noauth
sync
noaccomp
nopcomp
noccp
novj
holdoff 4
persist
maxfail 25
passive
asyncmap 0
lcp-echo-interval 2
lcp-echo-failure 7
#replace user@domain by your coorect info
name username
user username
plugin usr/lib/pppd/VERSION/pppoatm.so
VPI.VCI

Reemplaza username con tu nombre de usuario y VPI.VCI con los valores que indique tu ISP (e.g. 8.35) y VERSION con la versión de pppd (e.g. 2.4.1 o 2.4.2)

6) Ahora para conectar escribe amstart.sh y deberás ver el driver cargado, e iniciado, después escribe ifconfig para verificar que tienes las interfaz ppp0.

Si estas conectado debes ser capaz de hacer ping a una ip, intenta :


Quote:
ping 216.239.59.147

si esto funciona, parece que tu conexión funciona, ahora prueba la resolución DNS haciendo ping a una dirección web (si esto falla pasa al paso 7)

Quote:
ping www.google.com


Si “the host is unreachable” entonces edita /etc/resolv.conf y /etc/ppp/resolv.conf (si quieres puedes remplazar este fichero y crear un enlace a /etc/resolve.conf , para hacer esto escribe como root ln -sf /etc/resolv.conf /etc/ppp/resolve.conf ) y añade algo como lo siguiente :

Quote:
nameserver first_dns
nameserver second_dns

Debes indicar los DNS de tu SIP aquí en el mismo orden reemplazando first_dns y second_dns cons sus ips, si no las conoces entonces, búscalas en www.google.com :)
Para desconectar, ejecuta amstop.sh, para conectar nuevamente ejecuta amstart.sh (si esto no funciona entonces ejecuta amstop.sh, desconecta el cable USB del modem 10 segundos y después ejecuta amstart.sh)

7) Si el falla el paso 6 pero todo parece correcto y el modem no funciona intenta editar el código fuente de xdslusb (hay 2 ficheros, uno para el kernel 2.4 y el otro para el 2.6, están nombrados de acuerdo con el kernel al que están destinados :) )
en el directorio /usr/amedyn/init y cambia esto :


Quote:
#define UDSL_DEFAULT_RCV_BUF_SIZE 64
#define UDSL_DEFAULT_SND_BUF_SIZE 32

Tras este cambio es necesario compilar nuevamente el programa (comando make del paso 2)

8) Si quieres que tu PC conecte automáticamente al iniciar escribe como root en /usr/amedyn :

Quote:
make add_service

9) Para más ayuda por favor visita el foro en sourcefoge's zyxel 630-11 project y también mira en /var/log/message y /var/log/syslog para intentar detectar algún error (por favor no publiques estos ficheros en el foro!!! Pueden ser muy grandes)
